# Documentação Técnica (rascunho)

Este diretório centraliza os artefatos técnicos do projeto BingoController. Os arquivos recomendados para evolução da documentação são:

- `OVERVIEW.md`: visão geral do produto e contexto de negócio.
- `ARCHITECTURE.md`: componentes, integrações, diagramas e decisões.
- `DOMAIN.md`: modelo de domínio, entidades e regras de negócio.
- `TESTING.md`: estratégia e matriz de cobertura automatizada e manual.
- `SECURITY.md`: políticas de segurança, checklist de ameaças e plano de resposta.
- `OBSERVABILITY.md`: guias de logs, métricas, tracing e runbooks.
- `DEVOPS.md`: pipelines, ambientes, deploy, rollback e práticas de infraestrutura.
- `ROADMAP.md`: plano evolutivo priorizado e iniciativas estratégicas.

> Cada arquivo pode ser criado progressivamente seguindo as recomendações detalhadas no relatório técnico entregue junto com este commit.
