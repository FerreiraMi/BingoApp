# Documentação Técnica (rascunho)

Este diretório centraliza os artefatos técnicos do projeto BingoController. Todos os documentos foram criados como fotografias fiéis do estado atual e contêm marcações `//TODO` onde ainda faltam detalhes.

| Arquivo | Conteúdo |
| --- | --- |
| `OVERVIEW.md` | Contexto do produto, componentes e ambientes mapeados. |
| `ARCHITECTURE.md` | Topologia, componentes e fluxos técnicos atuais. |
| `DOMAIN.md` | Entidades (`User`, `Session`, `Viewer`) e regras vigentes. |
| `TESTING.md` | Situação da cobertura e próximos passos propostos. |
| `SECURITY.md` | Controles presentes, riscos identificados e ações sugeridas. |
| `OBSERVABILITY.md` | Estado de logs/métricas/tracing e lacunas operacionais. |
| `DEVOPS.md` | Stack de infraestrutura, Docker/Helm e recomendações de CI/CD. |
| `ROADMAP.md` | Plano priorizado curto/médio/longo prazo. |
| `RUNBOOK.md` | Procedimentos operacionais básicos e incidentes comuns. |
| `CONTRIBUTING.md` | Guia de setup, convenções e testes. |
| `CHANGELOG.md` | Histórico de alterações (formato Keep a Changelog). |
| `DECISIONS.md` | ADRs documentadas e pendentes.

> Atualize os arquivos conforme novas informações surgirem e substitua cada `//TODO` por conteúdo definitivo.
